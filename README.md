# Markdown Capture

An Android app that photographs documents, whiteboards, receipts, or anything else and turns them into markdown notes using a vision-capable LLM. The generated note and original image are saved directly to a folder on your device — works great with an Obsidian vault.

## What it does

1. Point the camera at something
2. Tap capture
3. The image is sent to an AI model, which writes a structured markdown note
4. The note and image are saved to your chosen folder, with YAML frontmatter containing GPS coordinates and address

All processing happens in the background — the camera stays ready for the next shot while the AI works.

## Features

- **Three capture modes** selectable via a tab row (swipe or tap):
  - **Capture** — quick note from anything visual
  - **Detail** — thorough analysis with more context
  - **Transcribe** — text extraction / OCR, with Mistral OCR support for scanned documents
- **Multi-provider** — configure OpenAI, OpenRouter, Google Gemini, Mistral, or any OpenAI-compatible endpoint (e.g. Ollama) independently per tab
- **Multiple lenses** — automatically detects wide/main/tele cameras; tap to switch, pinch to zoom
- **Location tagging** — YAML frontmatter includes GPS coordinates, place name, address, and a Google Maps link
- **Capture history** — last 20 captures accessible via a bottom sheet; re-open, share, or resubmit any of them
- **Share as PDF or Markdown** — from the capture view, share the rendered note as a PDF or the raw `.md` file
- **Mistral OCR** — when the Transcribe tab uses `mistral-ocr-latest`, embedded images in the scanned document are extracted and saved alongside the note as Obsidian wikilinks

## Setup

### Requirements

- Android 8.0 (API 26) or later
- An API key for at least one supported provider

### Build

```bash
./gradlew assembleDebug
```

Install the APK, or open the project in Android Studio and run it directly.

### First launch

1. Open the app and grant camera and location permissions
2. Tap the settings icon (top-right) and go to **API Keys** — add credentials for your preferred provider(s)
3. Under each tab section (Capture / Detail / Transcribe), choose the provider and model
4. Under **General**, tap **Output folder** and select (or create) the folder where notes should be saved
5. Return to the camera and start capturing

## AI providers

| Provider | Notes |
|----------|-------|
| OpenAI | GPT-4o, GPT-4.1 and mini variants |
| OpenRouter | Access to Claude, Gemini, Llama, and others via a single key |
| Google | Gemini 2.5 Pro, 2.0 Flash, Gemma 4 |
| Mistral | Pixtral vision models + `mistral-ocr-latest` for structured OCR |
| Custom | Any OpenAI-compatible endpoint — enter a base URL and API key |

Each of the three capture tabs can use a different provider and model, so you can route quick notes to a cheap model and detailed analysis to a more capable one.

## Output format

Each capture produces:

```
{output_folder}/
  {date}-{name}.md                          ← AI-generated note with YAML frontmatter
  _resources/{date}-{name}/image.jpg        ← captured photo
  _resources/{date}-{name}/extracted-1.jpg  ← images extracted by Mistral OCR (if any)
```

The filename is generated by the LLM from the note content. If a note with the same name already exists for that date, `-2`, `-3`, … is appended. Frontmatter always includes the model used; location fields are added when GPS is available:

```yaml
---
model: gpt-4o-mini
latitude: 59.9139
longitude: 10.7522
place: Oslo
address: Stortingsgata 22, 0161 Oslo
map: https://www.google.com/maps?q=59.9139,10.7522
---
```
